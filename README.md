# kg-publicacoes

Hospedagem pública (GitHub Pages) **somente** dos slides finais aprovados dos carrosséis da KG Fonoaudiologia (@suafononline), usados pelo Buffer para publicar no Instagram.

- Estrutura: `slides/<ID>/<versao>/slide-0N.png` — `versao` = hash curto da versão aprovada.
- Arquivos são imutáveis: nunca são sobrescritos nem apagados enquanto vinculados a publicações.
- Não contém briefings, roteiros, credenciais nem informações de pacientes.
- `slides/_teste/` contém apenas imagens neutras de teste técnico.
